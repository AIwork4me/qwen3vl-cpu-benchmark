## Conclusions
1. The 'CPU' device is served by libopenvino_intel_cpu_plugin.so (OpenVINO intel_cpu plugin; same binary family serves x86-64 CPUs regardless of vendor).
2. oneDNN is STATICALLY embedded in that plugin (no dynamic libdnnl anywhere on the process path; 0 exported dnnl_* symbols). Exact oneDNN version is printed by the ONEDNN_VERBOSE header (captured in Phase 3).
3. CPU threading runtime = bundled oneTBB 2021.13.1 (libtbb.so.12); no OpenMP linked.
4. Embedded oneDNN dispatch tables contain implementation suffixes incl. avx512_core_vnni, avx2_vnni, avx512_core, avx512_core_bf16, avx10_*; env knobs compiled in: ONEDNN_VERBOSE / ONEDNN_MAX_CPU_ISA / ONEDNN_JIT_DUMP / ONEDNN_JIT_PROFILE / ONEDNN_CPU_ISA_HINTS (names stored suffix-only in .rodata, runtime-prefixed).
